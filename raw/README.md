# 客片源图暂存区（raw/）

把真实客片按分类放进对应的子文件夹即可，剩下的交给 AI 处理：

```
raw/
├── 领证跟拍/
├── 写真/
├── 订婚跟拍/
└── 宝宝宴/
```

## 规则
- **文件名随意**（如 `IMG_1234.jpg`、`张三领证.jpg`），处理时会自动重命名为 `p1.jpg`、`p2.jpg`… 并写入 `src/data.ts`。
- **格式支持**：`.jpg` / `.jpeg` / `.png` / `.webp`（手机/相机导出的都行）。
- **横图竖图都行**，AI 会读取真实尺寸填进 `width/height`，瀑布流比例自动正确。
- 建议每类先放 **2–5 张最出片的**，启动期不用一次塞满。

## 处理流程（AI 自动做）
1. 读取各分类文件夹里的图
2. 压缩到网页尺寸（长边 ≤ 1600px，JPEG 质量 ~82，去除 EXIF 隐私信息）
3. 输出到 `public/photos/pN.jpg`
4. 更新 `src/data.ts`（src + 真实宽高 + 分类 + 标题）
5. 重建 → 部署 OSS → 刷新 CDN

> 注意：`raw/` 只是本地源图区，**不会被部署上线**。
